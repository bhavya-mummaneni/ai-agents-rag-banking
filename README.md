# Enterprise AI Agents & RAG for Banking Compliance

**Role:** AI Engineer, Goldman Sachs (Aug 2025 – Present)

> This work was delivered inside a regulated banking environment. The source code is proprietary and cannot be published; this page documents the problem, the approach, the stack, and the measured outcomes.

## Problem

Banking teams needed an AI assistant that could reach organizational data and answer questions grounded in regulated compliance policies, where every answer has to be traceable and auditable.

## What was built

- **Copilot Studio + Microsoft Graph integration** — connected the assistant to organizational data sources, improving data accessibility across workflows.
- **RAG pipelines** — LangChain, embeddings, and vector databases retrieve the relevant policy passages before generation, so answers are grounded in current compliance documents for analyst decision support.
- **Agent tool/function calling** — streamlined how agents invoke tools and functions, improving system responsiveness.
- **Audit logging and data lineage** — comprehensive tracking of data and decisions, improving data integrity and traceability for compliance review.
- **Fraud detection models** — Python and TensorFlow models with feature engineering, improving banking risk visibility and secure transaction review.
- **Model evaluation, monitoring, and governance** — validation practices that reduce release risk for credit risk platforms.
- **Data pipelines** — PySpark, SQL, and Airflow pipelines improving feature availability for predictive analytics.

## Measured outcomes

- **25% increase** in application performance (Copilot Studio / Microsoft Graph integration)
- **40% improvement** in compliance audit outcomes (audit logging and data lineage)
- **50% reduction** in agent tool/function calling latency
- **30% reduction** in vulnerabilities (security automation in production software)

## Stack

Python · LangChain · RAG · embeddings · vector databases · Copilot Studio · Microsoft Graph · TensorFlow · PySpark · SQL · Airflow · model evaluation and governance
